## 1. 概要

**目的**

- 管理者が既存の**配送方法**を編集できる画面。基本情報（表示名、販売種別）、**取り扱う支払方法との紐付け**、**お届け時間帯**、**都道府県別送料**、内部メモ、表示状態を設定する。

**システム上の役割**

- チェックアウトで顧客に表示される**配送方法**、**住所（都道府県）に基づく送料**、および当該配送方法を選択した際に**利用可能な支払方法**を決定する。

**対象ユーザー**

- EC-CUBE管理画面にログイン済みの管理者。

## 2. スコープ

**スコープ内**

- URLの `id` に基づき、`Delivery` の編集画面を開く。
- 各ブロックの編集：**基本情報**、**取り扱う支払方法**、**お届け時間設定**、**都道府県別送料設定**、**店舗メモ**（使用時）。
- **登録**で保存。保存前に**表示**（表示/非表示）を選択可能。**配送方法一覧**で一覧へ戻る。

**スコープ外**

- **決済ゲートウェイ**の実接続設定（GMO等）— 支払方法画面 / env / Customizeで管理。本フォームの対象外。
- 実際の配送オペレーション（配送業者API）— ショップが未連携の場合。

## 3. 画面構成・機能

- EC-CUBE **ヘッダー**（ショップ名、管理者アカウント）。
- **左メニュー：** **設定** → **店舗設定** → **配送方法設定**。
- **メインコンテンツ：** カードを順に表示 — 基本情報 → 支払方法 → お届け時間 → 都道府県別送料 → 店舗メモ。
- **コンバージョンバー（ページ下部）：** **配送方法一覧**、**表示**ドロップダウン、**登録**ボタン。

## 4. パラメータ・パス

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id`（URL） | 数値 | あり | `dtb_delivery` のレコードID。例：`/admin/setting/shop/delivery/3/edit` → `id = 3`。 |

**アクセス条件**

| 項目 | 値 |
| --- | --- |
| URLの例（ローカル） | `http://localhost:8080/index.php/admin/setting/shop/delivery/3/edit` |
| 権限 | EC-CUBE **管理画面**ログイン済み（**店舗設定**の編集権限あり）。 |

**メニュー遷移（サイドバー）**

- **設定** → **店舗設定** → **配送方法設定**
- ページタイトル（ブロックタイトル / サブ）：**配送方法設定** · **店舗設定**

## 5. データソース

| ソース | 説明 |
| --- | --- |
| `dtb_delivery` | 表示名、サービス名、問い合わせ番号URL、販売種別、表示状態、説明/メモ等。 |
| `dtb_delivery_fee` | 当該deliveryに紐づく都道府県（Pref）別送料。 |
| `dtb_delivery_time` | お届け時間帯の選択肢（設定時）。 |
| Payment紐付け | 当該deliveryで利用可能な支払方法の一覧（コアの多対多リレーション）。 |
| `ProductType`（販売種別） | deliveryに紐づく販売種別（例：販売種別A）。 |

## 6. 画面状態

**6.1 初期表示**

- deliveryレコードに基づきフォームが入力済み。各都道府県の送料、支払方法チェックボックス、お届け時間一覧がDBを反映。

**6.2 保存成功**

- **登録**後、EC-CUBE標準の成功メッセージを表示（バージョン/設定により編集画面に留まるか遷移するか異なる）。

**6.3 バリデーションエラー**

- **必須**フィールドの未入力 / 送料が不正 / 支払方法の選択不足（フォームルールに従う）：各フィールドにエラーを表示。

**6.4 特記事項**

- **全国一律** + **各都道府県に適用**ボタン：入力済みの金額を**すべて**の都道府県送料欄にコピー（デフォルトテンプレートのクライアントサイド処理）。値がDBに反映されるのは**登録**時のみ。

## 7. レイアウト

**7.1 デスクトップ（ツリー構成図）**

```
Admin EC-CUBE ページ
 ├─ Header
 ├─ Sidebar: 設定 → 店舗設定 → 配送方法設定
 └─ メインエリア
     ├─ Card 基本情報
     │   ├─ 配送業者名（必須）     [form.name]
     │   ├─ 配送方法名称（必須）   [form.service_name]
     │   ├─ お問い合わせ番号URL   [form.confirm_url]（？ツールチップ）
     │   └─ 販売種別（必須）       [form.sale_type]（？ツールチップ）
     ├─ Card 取り扱う支払方法（必須）[form.payments]
     ├─ Card お届け時間設定
     │   └─ 入力欄 + 新規作成 + ドラッグ＆ドロップ一覧（↑↓）
     ├─ 補足: 項目の順番はドラッグ＆ドロップでも変更可能
     ├─ Card 都道府県別送料設定（必須）
     │   ├─ 一括適用行: [free_all] + 各都道府県に適用
     │   └─ 47都道府県 + 送料入力欄 ¥ (#set_fee_all)
     ├─ Card 店舗メモ（折りたたみ）
     └─ コンバージョン: [配送方法一覧] ... [表示▼] [登録]
```

**7.2 ラベルとエンティティの対応**

- コアの日本語ロケールでは：**`admin.setting.shop.delivery.delivery_name`** = **配送業者名**（`Delivery` の **`name`** プロパティに対応）、**`delivery_service_name`** = **配送方法名称**（**`service_name`** に対応）。

**7.3 モバイル / 狭い画面**

- 同一コンテンツ。Bootstrapによりレイアウトが縮小。サイドバーは非表示になる場合がある。

**8.0 サマリーテーブル（スクリーンショット環境の例）**

| 部品 | ラベル（JA） | 説明 | 例 |
| --- | --- | --- | --- |
| 名前（DB `name`） | 配送業者名 | 配送業者/配送元の名称 | Cty ABC for GMO |
| サービス名（`service_name`） | 配送方法名称 | 顧客に表示される配送方法名 | ABC for GMO |
| 問い合わせURL | お問い合わせ番号URL | 追跡番号照会リンク（ショップ任意） | 空欄 |
| 販売種別 | 販売種別 | `ProductType` ドロップダウン | 販売種別A |
| 支払方法 | 取り扱う支払方法 | 各paymentのチェックボックス | GMO Direct, 郵便振替, … |
| お届け時間 | お届け時間設定 | 行追加 + 並べ替え | 設定依存 |
| 都道府県別送料 | 都道府県別送料設定 | ¥ / 都道府県、一括適用可 | 北海道 404, … |

| 一覧へ戻る | 配送方法一覧 | 一覧リンク | — |

| 保存 | 登録 | フォームPOST | — |

**8.1 基本情報ブロック**

*配送業者名（必須） — `name`*

| 属性 | 内容 |
| --- | --- |
| 意味 | 配送業者名（JA バンドルのキャリアラベル） |
| 必須 | あり |

*配送方法名称（必須） — `service_name`*

| 属性 | 内容 |
| --- | --- |
| 意味 | 配送方法（サービス）名 |
| 必須 | あり |

*お問い合わせ番号URL — `confirm_url`*

| 属性 | 内容 |
| --- | --- |
| 意味 | 追跡番号照会用URL（ショップが使用する場合） |
| 必須 | なし（ヘルプアイコンあり） |

*販売種別（必須） — `sale_type`*

| 属性 | 内容 |
| --- | --- |
| 意味 | EC-CUBE内の商品種別/販売チャネルとdeliveryを紐付け |
| 必須 | あり（ツールチップ付き） |

**8.2 取り扱う支払方法**

- ショップに登録されている `Payment` ごとの**チェックボックス**一覧。
- カード上に**必須**：フォームバリデーションに従い有効な選択が必要（通常、設定により最低1つ）。
- 支払方法を選択しない場合 → チェックアウトでこのdeliveryを選択した際、その支払方法は**利用不可**となる（コアの制約がこれを適用する場合）。

**8.3 お届け時間設定**

- 時間帯名の入力欄 + **新規作成**ボタン：`delivery_times` コレクションに行を追加。
- 各行は admin プロトタイプに従い **↑↓**、**削除**、**表示/非表示**（トグル）が可能。
- 表示順はドラッグ＆ドロップ / ボタンで変更可能（送信時に `sort_no` を更新）。

**8.4 都道府県別送料設定**

- **全国一律**：金額を入力（フォーム `free_all`） → **各都道府県に適用**でフォーム内の全都道府県の `fee` 欄にコピー（JavaScript `#set_fee_all`）。数値でない場合 → メッセージ `admin.setting.shop.delivery.fee.invalid` で `alert`。
- その下に**47都道府県**（都道府県ラベル + 送料入力欄）。

**8.5 店舗メモ**

- **description** エリア（折りたたみ可能）。内部メモの用途をツールチップで説明。

**8.6 コンバージョンバー**

| 位置 | 部品 | 機能 |
| --- | --- | --- |
| 左 | 配送方法一覧 | `admin_setting_shop_delivery` へ遷移 |
| 右 | 表示 | deliveryの表示状態 |
| 右 | 登録 | フォーム全体を保存 |

## 9. ビジネスロジック

- **販売種別**：注文内の商品種別に基づき利用可能な配送方法を絞り込み/紐付け（EC-CUBEコアのルールに従う）。
- **支払方法**：**配送方法 + 支払方法**の組み合わせを制約し、顧客に表示する。
- **都道府県別送料**：配送先住所の都道府県から送料を算出。
- **表示** = 非表示 → ストアフロントでこの配送方法は選択不可（コアの `visible` の使い方に準拠）。

## 10. イベント・処理

| イベント | システム動作 |
| --- | --- |
| 配送方法一覧をクリック | GET で配送方法一覧へ遷移 |
| 各都道府県に適用 | JSで全送料欄を設定（事前に数値バリデーション） |
| 新規作成（お届け時間） | DOMにプロトタイプを追加、sort を更新 |
| ドラッグ＆ドロップ / ↑↓ 時間帯 | 送信前に `updateSortNo` |
| 登録 | POST → バリデーション → `Delivery`、fees、times、paymentsを保存 |
| 表示を変更 | 登録時にフォームと共に送信 |

- **管理者**ログインおよび**店舗設定** / delivery の編集権限が必要。
- 管理画面に未ログインの場合、URLにアクセス不可。

## 13. 外部連携

- 本フォームには配送業者API設定欄は**なし**。問い合わせ番号URLはショップが手入力する静的フィールド。
- **GMO / 決済ゲートウェイ：** **取り扱う支払方法**チェックボックスを通じて間接的にのみ表示（例：**GMO Direct** が payment として存在する場合に選択）。GMO接続の詳細は `app/Customize/README_GMO_DIRECT.md` および**支払方法**画面を参照。

## 15. エッジケース

- URL の **id** が存在しない：404 または該当エラーを返す。
- **一括適用**で数値以外の値：警告を表示、欄には設定しない。
- **お届け時間を全削除**または空欄のまま：バリデーション / チェックアウトフローに依存（少なくとも1つのスロットが必須とは限らない）。
- **支払方法を1つも選択しない**（フォームが許容する場合）：保存時エラー、または当該deliveryでの決済不可となる可能性あり。
- **都道府県別送料** = 0 と空欄の違い：EC-CUBEのルールに従い確認（通常は具体的な数値を入力）。

## 16. ログ・監視

- 管理ログはEC-CUBEの設定に依存。
- **都道府県別送料**や**取り扱う支払方法**を変更した後は、チェックアウトのテストを推奨：複数都道府県、複数支払方法、**代金引換**（使用時）を確認。

## 17. テスト観点

**主要フロー**

- 有効な URL + `id` → フォームがDB内容と一致（例：配送業者名 / 配送方法名称、送料サンプル）。
- 1つの都道府県の送料を変更 + **登録** → 再度開く → 値が保持されていること。
- **各都道府県に適用** → 全欄が同じ値 → **登録** → DB同期を確認。

**エラー**

- 必須フィールドが空 → フォームエラーを表示。
- 一括適用で数値以外の文字 → alert / 欄を上書きしない。

**エッジ**

- **お届け時間**の追加 / 削除 / 並べ替え → 保存 → ストアフロント上の表示順（表示する場合）が正しいこと。
- 支払方法の選択を外す → チェックアウトで当該 delivery + payment の組み合わせが表示されないこと。
- **表示**を非表示 → ストアフロントでこの配送方法が選択できないこと。
